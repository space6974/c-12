# C프로그래밍1 - 함수와 변수 실습

강의자료 `C프로그래밍1_함수와변수.pptx`의 예제 및 LAB 코드를 실행 가능한 C 소스 파일로 정리했습니다.

## 포함 내용
- 지역 변수의 생존 기간, 함수 매개 변수의 값에 의한 호출
- 전역 변수, 지역 변수와 전역 변수의 이름 중복
- auto, register, volatile, static 저장 유형
- LAB: 은행 계좌 구현, 한 번만 초기화하기
- extern을 이용한 전역 변수 참조 및 파일 간 연결
- 함수 앞의 static 예제
- LAB: 난수 발생기 (random.c와 main.c를 함께 컴파일)
- 가변 매개 변수 합계
- 재귀: 팩토리얼, 2진수 출력, 최대공약수, 하노이 탑

## 컴파일
단일 `.c` 파일은 GCC에서 다음처럼 컴파일합니다.

```bash
gcc -std=c11 -Wall -Wextra 파일명.c -o program
```

멀티파일 예제는 해당 폴더 안에서 실행합니다.

```bash
gcc -std=c11 -Wall -Wextra linkage1.c linkage2.c -o linkage
gcc -std=c11 -Wall -Wextra main.c sub.c -o static_example
gcc -std=c11 -Wall -Wextra main.c random.c -o random
```

## 참고 및 실행상 주의
- 강의자료의 팩토리얼 예제는 변수 이름이 `x`, `f`, `n`으로 혼재하고 입력/출력 서식 문자열이 깨진 부분이 있어 정상 실행되도록 `n`으로 통일했습니다.
- 강의자료의 `volatile` 예제는 실제 하드웨어 포트가 있어야 대기 조건이 바뀝니다. 일반 PC에서 무한 반복하지 않도록 예시용 처리로 구성했습니다.
- 난수 발생기 LAB은 강의자료의 `random_i()` 및 `random_f()`를 분리 파일로 구성했습니다. 실행 시 0~100 범위로 표시하도록 `% 101`을 적용했습니다.
- `static` 함수 예제의 `f1()`은 파일 내부에서만 사용 가능하다는 점을 보여주며, 외부에서 호출되는 함수는 `f2()`입니다.
- 중간 점검 문제는 코드 실습이 아니라 개념 확인 문항이므로 소스 파일에는 포함하지 않았습니다.
